{% translate "À qui s’adresse le studio ?" %} +

{% translate "Aux créateurs qui veulent faire découvrir leurs vidéos à de nouvelles communautés, aux formateurs qui souhaitent adapter leurs cours et aux entrepreneurs qui présentent leur offre à des clients internationaux." %}

{% translate "Dans combien de langues puis-je doubler ma vidéo ?" %} +

{{ target_language_count }} {% translate "langues sont disponibles dans le studio. Vous pouvez sélectionner plusieurs langues pour une même vidéo ; les crédits sont calculés par minute entamée et par langue produite." %}

{% translate "Faut-il tourner une nouvelle vidéo pour chaque langue ?" %} +

{% translate "Le doublage part de votre vidéo existante : les images restent les mêmes et la parole est adaptée dans une autre langue. Avant de publier, prenez le temps de vérifier le sens, les noms propres et les termes techniques." %}

{% translate "Quelle différence avec les sous-titres ?" %} +

{% translate "Les sous-titres affichent le texte à l’écran. Le doublage permet d’écouter les explications dans une autre langue, notamment pour suivre un tutoriel ou une démonstration sans lire chaque phrase." %}

{% translate "Le doublage conserve-t-il ma voix ?" %} +

{% translate "Oui. Dublao conserve la voix originale des intervenants pour restituer leurs paroles dans la langue choisie. La parole traduite est générée par l’IA à partir de leur voix, plutôt qu’avec une voix générique choisie dans un catalogue." %}
